# The Spark & the Woven Person — Windows Build Kit

This kit wraps the four animated shorts in a dedicated Electron desktop window and builds both a Windows Setup installer and a portable `.exe` through GitHub Actions.

## What is included

- The original Vite/React project and its four animated films.
- A secure Electron desktop entry point (`electron/main.cjs`).
- `electron-builder.yml` configured for Windows NSIS Setup and portable targets.
- `.github/workflows/build-windows-installer.yml`, ready for GitHub Actions.

The animation, canvas rendering, and synthesized ambience run locally in the app. The app does not require a separate PostgreSQL server or a separately installed Node.js runtime on the computer where it is played.

## Build the Windows files

1. Extract this ZIP.
2. Create an empty GitHub repository, for example `The-Spark-and-the-Woven-Person`.
3. Upload **everything inside the extracted folder directly into the repository root**. Do not upload the outer ZIP or an extra enclosing folder. The repository root should contain `package.json`, `package-lock.json`, `index.html`, `src/`, `electron/`, `electron-builder.yml`, and `.github/workflows/`.
4. Commit the files.
5. Open the repository's **Actions** tab. The workflow named **Build The Spark and the Woven Person Windows App** should start automatically. You can also select it and choose **Run workflow**.
6. When the run succeeds, open its **Summary** and download the artifact named `The-Spark-and-the-Woven-Person-Windows-Installers`.
7. Extract the artifact ZIP. It contains a Setup `.exe` and a portable `.exe`.

## Build details

- The workflow uses `npm install`, not `npm ci`, so npm can reconcile the added Electron build dependencies with the original lockfile.
- `npm run build` runs the original Vite single-file production build.
- Electron loads `dist/index.html` directly in its own application window.
- The installer and portable targets are x64 Windows builds.

The `.exe` files are generated by GitHub Actions; this kit itself is not a prebuilt installer. The first GitHub build is the final verification of the packaging environment.
